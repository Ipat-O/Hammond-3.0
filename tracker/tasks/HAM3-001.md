# HAM3-001 — Desktop application foundation

State: `in_design`  
Worker: Claude Code / Claude Sonnet 5  
Auditor: Kilo Code / DeepSeek V4 Pro  
Depends on: none

## Outcome

Create the smallest runnable Tauri, React, and TypeScript desktop application that establishes Hammond 3.0's package, test, formatting, and native-command boundaries.

## Scope

- Initialize the repository and `dev` delivery branch conventions.
- Create the desktop shell and React application frame.
- Define typed native-command interfaces without implementing project features.
- Add unit, component, and native-side test entry points.
- Add development, build, lint, test, and packaging commands.
- Add architecture-boundary documentation for UI, native filesystem, Supabase, and local settings modules.

## Non-scope

Supabase schema, directory picker behavior, task UI, template editing, Git integration, or provider launching.

## Acceptance

- A clean checkout can install, test, build, and open a desktop window.
- The app does not require a browser server after packaging.
- No bridge or background polling architecture is introduced.
- Module boundaries allow HAM3-002 and HAM3-003 to proceed independently.

## Human check

Owner opens the packaged development application and observes the Hammond shell.
