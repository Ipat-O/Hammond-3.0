# HAM3-009 — Work-order generation and dispatch records

State: `in_design`  
Worker: Claude Code / Claude Sonnet 5  
Auditor: Kilo Code / DeepSeek V4 Pro  
Depends on: HAM3-004, HAM3-005

## Outcome

Generate self-contained worker, correction, and auditor prompts that explicitly identify every participant and delivery stage.

## Scope

- Copyable worker, correction, and audit prompt generation.
- Explicit human owner, Sol orchestrator, worker, and auditor identity blocks.
- Task ID, repository/directory, Git links when known, base/work branch, start/review SHA, scope, non-scope, acceptance, verification, evidence, and stop rules.
- Save immutable dispatched prompt snapshots and returned report records.
- Missing-link representation without invented URLs.
- Offer injection of the current work order into the selected directory.

## Non-scope

Calling providers, opening provider sessions, GitHub posting, automatic model routing, or reading provider conversations.

## Acceptance

- A recipient can execute from the prompt without Hammond access.
- Worker and auditor identities cannot be ambiguous.
- Audit prompts require a real PR URL and exact head SHA.
- Correction prompts name prior head, new expected role, and audit report.
- Stored dispatch content remains historically readable after templates change.

## Human check

Owner generates one Sonnet-worker/Kilo-auditor packet and one Kilo-worker/Sonnet-auditor packet.
