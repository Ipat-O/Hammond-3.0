# HAM3-003 — Local directory contexts and bindings

State: `in_design`  
Worker: Claude Code / Claude Sonnet 5  
Auditor: Kilo Code / DeepSeek V4 Pro  
Depends on: HAM3-001

## Outcome

Let the owner open, change, close, and resume local directories directly through the desktop application.

## Scope

- Native folder picker.
- Typed read/write/remove/existence/reveal commands constrained to the selected directory.
- Local-only project-to-directory bindings.
- Multiple directories linked to one project.
- Last-open directory and screen resume state.
- Missing/moved directory recovery UI.
- Treat ordinary folders, repositories, and Git worktrees uniformly.

## Non-scope

Git validation, branch discovery, remotes, dirty-state inspection, GitHub, or Supabase storage of absolute paths.

## Acceptance

- Picker returns or cancels immediately with no waiting state.
- Open/change/close works without a bridge or localhost service.
- Restart resumes an existing directory or clearly reports that it moved.
- Two worktree paths can link to the same project as separate local contexts.

## Human check

Owner opens a normal folder, a repository, and a worktree; restarts and changes between them.
