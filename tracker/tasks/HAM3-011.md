# HAM3-011 — Tracker depth, activity, search, and export

State: `in_design`  
Worker: Anthropic / Claude Code / Claude Sonnet (planning default; bind at dispatch)  
Auditor: Kilo Code / DeepSeek V4 Pro  
Depends on: HAM3-004, HAM3-009, HAM3-010

## Outcome

Restore the useful project-management depth from Hammond 2.0 without restoring its plumbing.

## Scope

- Task blockers and general relations.
- Links and lightweight attachments/attachment references.
- Unified project/task activity timeline.
- Search and filters across tasks, comments, reports, SHAs, and links.
- Board and list views.
- Project archive and portable Markdown/JSON export.
- Pagination for large activity sets.

## Non-scope

Git synchronization, provider transcript storage, multi-user collaboration, or complex analytics.

## Acceptance

- Relations prevent invalid self-links and cycles where relevant.
- Search returns understandable project-scoped results.
- Export contains durable Hammond memory but excludes local absolute paths and secrets.
- Activity identifies meaningful changes without recording noisy UI events.

## Human check

Owner searches a multi-task project, follows relations, and opens a readable export.
