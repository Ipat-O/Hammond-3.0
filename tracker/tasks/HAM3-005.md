# HAM3-005 — Versioned instruction template domain

State: `in_design`  
Worker: Claude Code / Claude Sonnet 5  
Auditor: Kilo Code / DeepSeek V4 Pro  
Depends on: HAM3-002

## Outcome

Preserve and simplify Hammond 2.0's valuable template/version model for orchestrator, worker, and auditor instructions.

## Scope

- Role templates for orchestrator, worker, and auditor.
- Provider variants for Codex, Claude Code, and Kilo Code.
- Immutable version history on every save.
- Active version selection and restoration.
- Shared role content, provider content, project override, and optional task work-order composition.
- Rendered preview service independent of filesystem writes.

## Non-scope

Heavy/light routing, model recommendation, per-session assignment, runtime manifests, or document injection.

## Acceptance

- Editing creates a new version and preserves old content.
- Restore creates/selects a traceable version without deleting history.
- Composition order is deterministic and tested.
- A project can select different versions by role and provider family.

## Human check

Owner edits a worker template, restores an earlier version, and compares the generated previews.
