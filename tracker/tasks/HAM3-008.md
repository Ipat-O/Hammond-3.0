## Outcome

Make opening Hammond immediately restore useful project context and make moving between repositories effortless.

## Scope

- Project home dashboard.
- Open/change/close directory controls.
- Link unrecognized directory to a new or existing project.
- Detect only Hammond-managed instruction presence.
- Offer instruction injection when absent.
- Display tasks, comments, active instruction selection, recent activity, and evidence summary.
- Resume last project, directory, task, and screen.
- Show multiple local directory contexts for one project.

## Non-scope

Git repository inspection, GitHub login, remote synchronization, or bridge status.

## Acceptance

- Opening a linked directory shows its existing Hammond project data.
- Opening an unlinked directory offers create/link without Git requirements.
- Missing instructions produce one optional action, not an installation wizard.
- Returning later restores where the owner left off.

## Human check

Owner moves among two repositories and one worktree and sees the correct task context each time.
