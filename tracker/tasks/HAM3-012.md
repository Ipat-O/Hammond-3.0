# HAM3-012 — Integrated desktop release and human QA

State: `in_design`  
Worker: OpenAI / Luna  
Auditor: Kilo Code / DeepSeek V4 Pro  
Depends on: HAM3-007, HAM3-008, HAM3-009, HAM3-010, HAM3-011

## Outcome

Integrate and package the first useful Hammond 3.0 release and prove the owner workflow end to end.

## Scope

- Production desktop packaging for the owner's operating system.
- First-run Supabase owner setup and recovery guidance.
- Seed/default templates for all three roles and provider families.
- Integrated error, loading, offline, and retry behavior.
- Data export and local-settings backup guidance.
- Focused automated integration suite across the first-release boundary.
- Named human QA script covering directory, project, task, instruction, dispatch, evidence, restart, and worktree flows.
- Remove dead scaffolding and document support boundaries.

## Non-scope

Auto-update infrastructure, multi-platform certification, multi-user support, Git/GitHub integration, provider launching, or automatic merge.

## Acceptance

- A fresh packaged install completes all eleven first-release user outcomes.
- No bridge, browser tab, localhost server, GitHub login, or Git inspection is required.
- Failures are visible, actionable, and do not leave indefinite waiting UI.
- Focused tests pass; a release-boundary full suite runs once on the exact approved head.
- Owner completes and records the human QA script.

## Human check

Owner performs the complete real workflow in a new directory, existing repository, and separate worktree, then restarts and confirms recovery.
