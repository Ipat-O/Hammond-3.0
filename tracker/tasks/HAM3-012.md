Integrate and package the first useful Hammond 3.0 release and prove the owner workflow end to end.

## Scope

- Production desktop packaging for the owner's operating system.
- Deliver the desktop installer plus HAM3-014 Docker/Compose service artifact and setup guidance. Verify hosted-Supabase access with the desktop closed, scoped instructions, reopen/reconnect reconciliation, live refresh, conflict protection and grant revocation.

Auto-update infrastructure, multi-platform certification, multi-user support, Git/GitHub integration, provider launching, or automatic merge.

## Acceptance

- A fresh packaged install completes the revised first-release outcomes in docs/ARCHITECTURE.md plus delivered HAM3-014 agent access and instruction scope acceptance; cancelled HAM3-009/010/011 scopes are excluded.
- The desktop remains native and usable independently of Docker. Agent access uses the D-023 standalone local Docker HTTP MCP service and hosted Supabase; no Windows MCP sidecar is required. No GitHub login or Git inspection is required for Hammond operation.
- Failures are visible, actionable, and do not leave indefinite waiting UI.
- Focused tests pass; a release-boundary full suite runs once on the exact approved head.
- Owner completes and records the human QA script.

## Human check

Owner performs the complete real workflow in a new directory, existing repository, and separate worktree, then restarts and confirms recovery.
