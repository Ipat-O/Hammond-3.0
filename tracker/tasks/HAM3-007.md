# HAM3-007 — Instruction Studio UI

State: `in_design`  
Worker: OpenAI / Luna  
Auditor: Kilo Code / DeepSeek V4 Pro  
Depends on: HAM3-005, HAM3-006

## Outcome

Provide one clear screen for editing, versioning, previewing, and injecting all Hammond instructions.

## Scope

- Role tabs and provider-family tabs.
- Markdown editor and rendered preview.
- Version timeline, comparison, notes, activation, and restore.
- Project override editor.
- Generated document and target-path preview.
- Inject, Update, Remove, and retry controls.
- Unsaved-change protection and visible local/Supabase state.
- Unmanaged-file conflict decision UI.

## Non-scope

Provider/model routing scores, agent launching, Git commits, or automatic task dispatch.

## Acceptance

- The owner always knows what content, version, role, provider, and path are active.
- Saved template changes can update the open directory immediately on owner command.
- Local injection failure does not lose the saved template edit.
- Accessibility and keyboard navigation cover core controls.

## Human check

Owner completes the full edit → save version → preview → inject → switch role → update flow.
