## Outcome

Provide one clear screen for assigning role execution providers and understanding, customizing, recovering, previewing, and injecting the effective instructions they receive.

## Scope

- A project-level **Agent assignment** section with distinct **Execution provider** choices for orchestrator, worker, and auditor.
- A default effective-instructions view headed by role and assigned provider, with project and active-version context.
- One primary editor; shared-role, provider-specific, and project-override layers live under **Customize** or **Advanced** disclosures.
- Explicit inheritance states such as “Using default” with a clear customization action; no unexplained blank inherited text areas.
- **Save changes** creates immutable versions without exposing version creation as a routine user decision.
- Version history drawer/modal with active and restore-provenance labels, comparison/notes where useful, and one clear **Restore this version** operation that explains it creates a new version.
- Markdown editor and rendered effective preview.
- Preview-only **Test a task-specific instruction** field with an explicit “won't be saved” explanation.
- Generated document and target-path preview.
- Inject, Update, Remove, and retry controls.
- Unsaved-change protection and visible local/Supabase state.
- Unmanaged-file conflict decision UI.

## Non-scope

Automatic provider/model routing scores, model recommendation, agent launching, Git commits, or automatic task dispatch.

## Acceptance

- The owner can distinguish “which agent performs this role?” from “which provider-specific instructions am I customizing?” without learning the layer model first.
- The owner always knows the effective content, active version, role, assigned execution provider, project, inheritance state, and target path.
- Most edits require only choosing a role, reading effective instructions, and selecting Customize, Save changes, History, or Restore this version.
- Saved template changes can update the open directory immediately on owner command.
- Local injection failure does not lose the saved template edit.
- Accessibility and keyboard navigation cover core controls.

## Human check

Owner assigns different worker and auditor execution providers, customizes effective instructions without opening Advanced first, restores history, then completes preview → inject → switch role → update.
