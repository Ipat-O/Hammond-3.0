# HAM3-004 — Core project and task tracker

State: `in_design`  
Worker: OpenAI / Luna  
Auditor: Kilo Code / DeepSeek V4 Pro  
Depends on: HAM3-002

## Outcome

Deliver the usable project and task memory at the center of Hammond.

## Scope

- Create, edit, archive, list, and open projects.
- Create, edit, archive, and move tasks.
- Implement statuses from `backlog` through `shipped`, including `cancelled`.
- Parent/child relationships.
- Basic comments.
- Optimistic UI with explicit save failure and retry.
- Project and task detail screens.

## Non-scope

Instruction injection, Git synchronization, automatic state transitions, attachments, advanced search, or evidence approval.

## Acceptance

- Project and task changes persist across restart.
- Invalid parent cycles and invalid statuses are rejected.
- Save failure leaves visible unsaved state rather than pretending success.
- `merged` and `shipped` remain distinct manual states.

## Human check

Owner creates a project, nested tasks and comments, changes statuses, and confirms persistence after restart.
